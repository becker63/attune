The pattern catalogue freezes 64 selected patterns and 49 cap-excluded candidates. Native rules preserve typed witness participants. The generator assembles syntax and does not evaluate production joins.

Specialization uses immutable configuration banks and sealed calibration/application boundaries. Search code stops at explicit prior-acquisition and evaluation boundaries; it does not make a compiled launcher into a completed experiment.

These docs were prepared while another agent was working on bounded search. The snapshot reference and report hashes define the material documented here. Incorporate future results only after their protocol and executed evidence are available.

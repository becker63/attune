The browser entrypoint installs the compiled Flix program and exports its `evaluate` call. Calls are serial. Java catches runtime exceptions as readable transport errors rather than empty successful answers. Algorithmic decisions stay in Flix.

The standalone Studio extractor is a statically linked ARM64 Linux musl executable. It packages grammar/program dependencies without a JVM or Nix dynamic loader on the Function. The ordinary library runner remains independently buildable.

Compiler, JDK, Grit grammars, Maven closure, Rust toolchains, and browser dependencies are pinned by the relevant module/lock files. The documented core compiler is Flix 0.76.1. Pins from a historical checkpoint are not claims about later dependency releases.

Build inputs exclude private configuration, agent state, personal packs, and the sibling reference checkout. The existing narrow credential helpers handle their own fields; credentials are not copied into build artifacts.

Distribution notices live in `web/THIRD_PARTY.md`. Frozen website assets are recorded by `web/release.json`. Generated outputs, inherited dependencies, and authored integration code have separate code-accounting roles.

Evidence has four different roles: a proposed prediction, an observed execution, a historical replay, and an authored fixture. Keep them distinct.

The frozen localization and ReviewBench TSVs remain in `evidence/`, with exact bytes recorded in `SHA256.json`. Current metric claims use the corrected summary, including ReviewBench's matching and recall-denominator repairs. The older chronology remains unchanged in Git history.

## Reproduction boundaries

Reading committed summaries needs no new model calls. ReviewBench publication can be regenerated with pinned cached inputs in a separate checkout of the archived implementation. Its `--nofetch` command fails if an input is missing. Larger localization source archives and external embeddings are not bundled.

Current law tests exercise current implementation contracts; they do not rerun every historical campaign. Model charges, compute cost, warm wall time, failed slots, and undefined metrics must retain their own availability states.

Before adding a new headline, record the exact protocol, population, denominator, prediction/evaluation separation, producing source revision, tool identities, and whether it is a new measurement or replay.

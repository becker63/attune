# Nix/Nim migration evidence

The baseline commit captures the preexisting working tree without changing the
original checkout. Scientific kernel changes in this commit were already present
in that tree; the migration must not alter their meaning. `baseline-manifest.json`
records the SHA-256 of every captured source/data file. The independently executable
Python baseline is retained in this commit and an external source snapshot.

No campaign, production service, paid inference request or physical disk operation
is authorized by parity validation. Tests use isolated frozen offline fixtures.

title: "Repository structure through time"
description: "A structural response instrument detects changes and exposes blind spots."
---

This October 7 study replayed immutable historical facts with the existing typed Atlas machinery. It did not run new extraction or provider calls. Its inventory recorded 87 checkpoints: four recomputed signatures, four controlled remapping accounts, and 79 without a recovered semantic signature.

The historical signature enumerates 3,279 well-typed routes per seed through depth seven. It uses eight File and eight Symbol singleton seeds ranked by identity hashes. Its metrics include extinction, normalized reach, depth survival, and physical evaluator reuse. These are distinct quantities.

## Consequential observations

| Observation | Interpretation |
| --- | --- |
| Cleanup reduced symbols 762 → 650, while files grew 72 → 75 and imports became denser. | Smaller source surfaces need not have lower retained coupling. |
| Symbol extinction jumped 50.923% → 56.267%, but shared seeds were nearly unchanged. | Identity turnover can imitate structural change. |
| Fifteen changed admission edges moved depth-two reach 0.413580 → 0.268519, while depth-seven reach changed little. | Shallow responses can reveal changes a deep endpoint hides. |
| Declared caching boundaries changed while retained signature curves stayed equal. | Important execution organization can lie outside the instrument's semantic basis. |

The newer Attune source census had no recovered whole-repository semantic world in this report. External JS/TS localization worlds could not fill that gap. Published and work-topology series have different protocols and populations.

A signature is useful when accompanied by source/fact identities, coverage, seed survival, and independent source differences. It is not an architectural quality score or a demonstrated predictor of future change.

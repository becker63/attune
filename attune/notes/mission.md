## Architecture
### Semantic ownership
- **Attune:** semantic world identity, nominal FileId/SymbolId, six atoms, exact typed frontiers, one relation application and small local exact memo.
- **Attune.Repository:** Grit wire projection, identity then conservative language-aware resolution/admission, forward facts and derived inverses, explicit refusals and earned scoped coverage.
- **Attune.Theory:** bounded canonical descriptors, native fixed-schema fragments, world-level shard evaluation and witness rows.
- **Attune.Study:** typed task inputs/intent, permitted prior and application joins, prediction/evidence/outcome ADTs, selection, checking and metrics.
- **Attune.AsciiTree:** one formatting-only bounded writer.
- **Attune.View:** thin typed route/grammar/proof/graph/application projections and minimal checked-snippet support. Core/Theory never import View for scientific meaning.

Keep Defines Files→Symbols, DefinedIn Symbols→Files, Imports/ImportedBy Files→Files, Calls/Callers Symbols→Symbols unchanged. Extract the three forward relations only and derive inverses once. World identity includes canonical origin, exact source content/epoch and frontend/admission semantics, not just a display name or commit. Exact sets, domains and worlds remain authoritative; illegal routes are classified failures, not empty success. Legal empty output retains its world/domain. Memo lookup uses world namespace, exact typed input and next atom; record hits/misses where real lookups occur and compare enabled/disabled answers through the same evaluator.

Maintain witness/no-match/unknown/failure and ObservedTrue/ObservedFalse/Unmeasured separately; failure is classified independently. Additional static/type-use evidence, task declarations, predictions and execution observations never silently become each other. Coverage is earned from acquisition and remains scoped/bounded; distinct supporter counts count entities, not proof paths. Parquet preserves these distinctions.

### Declared graph and invalidation
```
public catalog -> admitted analysis manifest
world source -> facts + Atlas index -> theory shards -> shared world index
issue + clean world -> task context
context + world index + frozen policy -> prediction
reference patch -> labels/source variants -> measurement receipts
immutable prediction + labels/receipts -> Flix scoring -> Parquet + ASCII
```
World artifacts are computed once per exact WorldId and shared across tasks and both applications. The theory population has at most 256 deterministically ordered candidates: one–three positive binary atoms, at most four roles/two outputs/one inequality, connected and anchored consumption with safe domains/outputs. Normalize role spelling, body order and duplicate conjuncts, not arbitrary logical equivalence. Use finite native Flix template families; intermediate rows carry candidate/world/scope. Start near 32 descriptors/shard and tune from measured action duration and output bounds, targeting meaningful remote actions rather than millisecond scheduling noise.

A task/intent/policy change does not rerun extraction; a descriptor change invalidates its shard and dependent joins, not source acquisition; extraction/admission changes invalidate world downstreams; gold-only changes invalidate scoring, not prediction. Physically separate public input and evaluator artifacts, enforce transitive action closures and sentinel tests. Store facts once/world in a versioned Parquet bundle with task/world/pair references and distinct predictions/gold files.

Bazel cannot discover analysis targets from execution-time Parquet rows. A native preparation test emits a bounded deterministic manifest to declared output; the integration owner admits that generated analysis input before the study invocation. This is manifest materialization, not feasibility gating or dynamic orchestration. Once frozen, one study invocation exposes the complete fan-out; no nested Bazel loops.

### Reference execution
Baseline/A/B/AB source variants are immutable declared tree artifacts, not mutable shared worktrees. Use pinned mechanical acquisition/patch/merge tools; Flix specifies and checks semantics. Source export excludes future history, solution/test/gold metadata and helpers from predictor closure. Evaluate both original test oracles and applicable regressions on the same common source, in each task's supplied environment. A alone need not solve B's newly introduced obligation. Test-patch collisions, unsupported harnesses, source conflicts, infrastructure and unrun checks remain distinct.

Process receipts contain request/source identities, declared and observed runtime/platform information where available, per-command exit status, bounded logs/artifacts, truncation, timeout/runtime/cleanup state and elapsed work. Exit zero does not prove required test identities ran. Source conflict leaves unrun joint checks Unmeasured. Pair labels require individually valid edits plus observed source conflict/reproducible joint failure, or automatic integration and every preregistered joint obligation passing for a negative. No model repair, hidden test changes or erased failed rows. Dispatch/image failures occurring before the action starts cannot magically produce in-action receipts; preserve actual failed/unrun execution evidence and classify it honestly in reporting, without a custom scheduler.

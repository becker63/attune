# Empirical repository discrimination through specialization

Do response differences repeat on other issues, and does that repetition justify a repository-specific localization policy? **This panel shows useful response contrasts, but does not validate specialization as the strongest deployment default.** The fixed Studio recipe with explicit Qwen fallback remains better overall. The primary shrinkage selector helps React and recovers much of the Studio benefit on Renovate/Pino, but its errors on other repositories erase the aggregate advantage over Studio.

These are cross-fitted results on previously exposed data. Each of 85 independent issue groups contributes once per procedure; repeated configurations, subset fits and shuffles are not independent observations. No outcome-driven refinement was performed.

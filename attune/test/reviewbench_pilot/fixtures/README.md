one is derived from a RETAINED heldout attempt artifact

record; nothing is invented and no raw frozen record was rewritten.

| `holdout-finals.tsv`, `holdout-final-findings.tsv` | the non-empty FINAL deliveries and their normalized findings |
| `holdout-checkpoints.tsv`, `holdout-checkpoint-findings.tsv` | the durable committed checkpoint rows exactly as the guard wrote them and their normalized candidates |

only retained attempt artifacts and calls no provider.

## Frozen heldout-confirmation judging fixtures (`VAL-STUDY-004`, judging half)

The heldout judging stages read these. They are the raw receipts of the ONE
independent judge acquisition of the frozen blinded holdout candidates
(`library/dsh-gate-evidence/holdout-judge/holdout-judge-policy-freeze.md`); every
one is copied byte-exact and no raw verdict was rewritten.

| fixture | source |
| --- | --- |
| `holdout-judged.tsv` | the frozen raw judge verdicts of the ONE heldout judge acquisition (13 candidate-bearing tasks, 59 candidates) |
| `holdout-adjudications.tsv` | the frozen raw source-grounded adjudications of every candidate the judge found no reference for (11 candidates over 3 tasks) |
| `holdout-judge-sessions.tsv` | the judge/adjudication session receipts (16 sessions: 13 judge + 3 adjudicate, 276637 provider-total tokens, 85 usage steps, 0 failures) |
| `holdout-judge-failures.tsv` | the judge failure record (empty: 0 failures) |

The heldout reference population is NOT a fixture: it is projected
provider-free by `//test/reviewbench_pilot:reviewbench_holdout_references` from
the 24 pinned holdout golden files declared in `MODULE.bazel`. The judged
reduction is `//test/reviewbench_pilot:reviewbench_holdout_judged`.



The generation scripts live in the mission library under
`library/dsh-gate-evidence/pilot-judge/` (`build-fixtures.mjs`,
`project-tool-outcomes.mjs`, `project-invocations.mjs`, `run-judge.mjs`).

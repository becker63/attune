title: "Coordination and parallel work"
description: "Structural witnesses support plans, with no completed full-panel claim."
---

The coordination work asked whether repository architecture could support multiple agents working in one worktree. It reused extraction, anchors, and structural questions to identify shared boundaries and propose independent or joint work.

A witness can support parallel work, a need for coordination, or an unknown result. Structural independence is evidence for a plan; it does not guarantee freedom from editing conflicts or shared build/test effects.

Witness-bearing policies, independent/joint plans, and ASCII views were implemented and fixture-tested. The original 32-pair panel did not produce a completed full-panel result. Current fixtures, historical corrected-v2 replay, and external executions remain separate records.

The consequential result is a boundary on what can be claimed. The code demonstrates explicit planning semantics. The retained evidence does not demonstrate a measured multi-agent throughput benefit over the original real panel.

The [repository-through-time study](/experiments/repository-history) provides related structural evidence, but graph locality and agent coordination are different outcomes.

The project accumulated campaign acquisition, transport, replay, and presentation machinery while testing repository structure. The later reduction kept semantic laws and frozen evidence while moving the complete campaign implementation into Git history.

## A smaller current library

The core retained effects, nominal identities, conservative admission, ordinary Datalog, scoring, and exact metrics. It removed the former JavaScript agent loop, generated transport layer, runtime Arrow/Parquet closure, and descriptor framework from the library. The website remains a separate web stack.

One source-count comparison in the design record reduced implementation from 10,275 to 4,713 authored lines. That checkpoint excluded the website and preceded later work. The stretch budgets remained exceeded; it is not the current total.

## Shared request-time artifacts

Studio initially retained repository work in browser storage. The remote-cache migration moved verified public source, complete per-file observations, and public vectors into Next cached functions. The browser recomputes Flix admission and ranking, while private questions and judgments stay transient.

Largest-first fan-out improved one cloud indexing observation, but a large file still dominated the critical path. A controlled runtime/query comparison then supported replacing server WASM with native Grit while retaining the original queries.

## Research returns as explicit packages

Native-pattern and specialization packages execute ordinary declared actions around concrete Flix functions. Generated syntax and BUILD projections are reported separately from authored logic. Research placement does not remove that logic from code accounting.

The architectural lesson is to make the expensive boundary explicit and test its identity. A shorter source surface, a cache hit, or a faster fixture alone does not establish better repository understanding.

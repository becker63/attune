# Repository specialization replay

This package reuses the native-pattern campaign’s immutable595 configuration banks.
Flix owns signed arithmetic, status-only fallback, concrete pooled/local selection,
recipient policy application and canonical BigInt metrics. No inference, new query
engine, browser evaluator or dynamic selector framework is introduced.

`Response` preserves strict metrics and constructs the operational response matrix.
`Fit` reads physically separated calibration rows. `Apply` reads a sealed profile and
the recipient bank/hash; `Evaluate` first receives the held label. `Project` only
projects actual fits for scratch/cost DAG fixtures. `Law` covers signed metric laws.
BUILD is assembled by `../tools/specialization_build.py`, with ordinary declared
Bazel actions; mutation/cost assemblers append scratch targets. These science actions
are manual. Runtime execution, not successful compilation, produces the evidence.

The measured experiment and tested commands are in
`/home/becker/experiments/attune-repository-specialization-20261013/`.
Python scripts under the existing owned tools package assemble/slice immutable inputs,
check native decisions independently and reduce sealed results. They do not provide
production policies. All authored experiment logic is counted, including reports and
reference checks; generated BUILD projections have separate byte/line counts.
